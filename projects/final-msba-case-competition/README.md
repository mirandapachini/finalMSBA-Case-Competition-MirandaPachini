---------------------
Built an end-to-end churn prediction pipeline that produced a CatBoost model with strong out-of-sample performance (ROC–AUC 0.896). The project includes EDA, feature engineering, model selection, and deployment recommendations aimed at reducing churn while protecting ARPU.
