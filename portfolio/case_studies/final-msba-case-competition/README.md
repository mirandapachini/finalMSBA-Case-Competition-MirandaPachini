Final MSBA Case Competition — Telecom Churn Prediction
=====================================================

Quick summary
-------------
This case study demonstrates end-to-end work to predict customer churn for a telecom provider. It includes exploratory analysis, feature engineering, model training and evaluation, segmentation, and deployment recommendations.
